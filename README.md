# 顧客管理Webアプリ Ver.1

HTML・CSS・JavaScript・Google Apps Scriptを使用して制作した、
顧客情報・来店履歴・売上情報を管理できるWebアプリです。


## 概要

顧客情報の登録・検索・更新、来店履歴の記録、
売上や顧客状況の集計を行える顧客管理Webアプリです。

ひとつの顧客管理システムを、技術構成ごとに段階的に発展させる
ポートフォリオプロジェクトの第1バージョンとして制作しました。


## Live Demo

実際に動作するWebアプリを公開しています。

デモ環境では、すべて架空の顧客データを使用しています。
新規顧客登録・来店登録・顧客検索・顧客情報編集などを実際に操作できます。

> 公開デモのため、登録・編集によって表示されるデータが変更されている場合があります。
> 個人情報などの実データは入力せず、動作確認用としてご利用ください。


## 主な機能

- 新規顧客登録
  - 顧客名、誕生日、担当スタッフ、特徴、メモを登録
  - 初回来店日と会計金額を同時に記録
  - 顧客写真を複数登録可能
  - 類似する顧客を表示し、重複登録を防止

- 常連顧客の来店登録
  - 登録済み顧客を検索して選択
  - 来店日、会計金額、担当スタッフ、来店メモを追加
  - 顧客の来店回数や累計売上などを確認

- 顧客検索
  - 顧客名、顧客ID、特徴などから検索
  - 条件による絞り込みと並び替え
  - 検索結果から顧客詳細画面へ移動

- 顧客詳細
  - 基本情報、来店履歴、メモ、売上情報をタブ形式で表示
  - 顧客情報の編集
  - 登録写真の確認と代表写真の設定

- 特徴タグ管理
  - Googleスプレッドシートのタグ情報を動的に表示
  - タグの追加、名前変更、削除
  - 顧客ごとに複数の特徴タグを設定

- ホーム・サマリー
  - 顧客数、売上、今月の誕生日、新規登録数を表示
  - 写真・誕生日・メモ・特徴の未登録件数を表示
  - 最近追加した顧客、最近見た顧客を表示
  - 売上や来店状況を集計したサマリーを表示

```text
  └─ Google Drive

```

## 工夫した点

### Googleスプレッドシートをデータベースとして活用

顧客情報・来店履歴・顧客写真・特徴タグを役割ごとに分け、
顧客IDを使ってデータを関連付けています。

Google Apps Scriptを介して、
ブラウザからデータの取得・登録・更新を行う構成にしました。

### 顧客の重複登録を防止

新規顧客登録時に入力された顧客名をもとに、
登録済みの似ている顧客を候補として表示します。

候補から顧客情報を確認できるようにし、
同じ顧客を重複して登録するリスクを減らしています。

既存顧客だった場合は、新規登録画面で入力した来店日・会計金額・
担当スタッフ・メモを保持したまま、常連顧客の来店登録へ移動できます。

### 特徴タグを動的に管理

特徴タグをHTMLへ固定で記述せず、
Googleスプレッドシートから取得して動的に表示しています。

タグの追加・名前変更・削除にも対応し、
画面側を修正しなくても特徴タグを管理できるようにしました。

### 顧客写真の管理と表示速度の改善

顧客写真はGoogle Driveへ保存し、
スプレッドシートにはファイルIDや写真URLなどの情報を保持しています。

写真の保存・読み込み処理を見直し、
複数写真を登録する場合でも待ち時間を抑えられるよう改善しました。

### データから自動で集計

ホーム画面やサマリー画面では、
顧客マスタと来店履歴のデータから売上・来店数・顧客数などを集計しています。

画面に固定した数値ではなく、
Googleスプレッドシートの実データをもとに表示内容が変化するようにしました。

### 同日のデータでも表示順が安定するように調整

同じ日付の顧客登録や来店履歴が複数存在する場合でも、
登録日時やIDを追加の比較条件として使用し、
表示順が不安定にならないようにしています。


## 動作確認

Ver.1では、実際の利用を想定した操作で以下の動作を確認しています。

- 新規顧客の登録とGoogleスプレッドシートへの保存
- 登録済み顧客への来店履歴の追加
- 顧客情報の編集と再読み込み後の保存内容の維持
- 類似顧客の表示・確認と常連顧客登録への引き継ぎ
- 顧客写真の登録と代表写真の表示
- 売上・来店数・顧客数などの集計結果
- 同じ日付のデータが複数ある場合の表示順


## Ver.1の対応範囲

Ver.1では、顧客情報の登録（Create）・参照（Read）・更新（Update）を実装しています。

顧客データの削除・復元はVer.1では対象外とし、
今後のバージョンでの機能追加を予定しています。
